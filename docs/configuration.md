# fly.board configuration reference

All settings are plain `key=value` files in the site root, loaded at startup
by `engine_settings_load()` (`src/engine/settings.c`). Lines without `=` and
unknown keys are ignored. **Restart the service after editing.** Most files
are auto-generated with defaults (and comments, where non-obvious) on first
run. This reference covers every key; for performance knobs see
[TUNABLES.md](../TUNABLES.md).

## admin.settings

Two raw lines, no keys:

```
admin
change-me-now
```

Line 1 = admin username, line 2 = admin password (`auth_admin_load()`,
`src/auth/auth.c`). If the file is missing it is created with
`admin` / `fly.board`. Legacy `id=` / `pw=` prefixes are stripped on load.
The account is created/re-synced in the `users` table as site admin on every
startup. This file is treated as a **secret**: it is only included in backups
made with `--with-secrets`, and listed in `k_secret_paths`.

## fonts.settings

Typography. Loaded by `font_settings_load()` with built-in defaults; a
missing file is regenerated with every key, so the generated file is the
reference. Key groups:

- `font_import_url`, `font_face_family`, `font_face_src` — external font CSS
- `font_file=<basename> <http(s)://url>` — fonts downloaded at startup into
  `public/fonts/` when missing (basename must not contain `/` or `\`)
- `font_body`, `font_heading`, `font_ui`, `font_code`, `font_blockquote`,
  `font_display` — font stacks
- `letter_spacing_*` — per-element tracking (body, h1–h5h6, topbar title,
  btn, board line, hero, md headings, post h1)
- `font_weight_*` — per-element weights

## s3.settings (optional)

S3-compatible object storage for uploads. All keys empty = local disk only.
Loaded by `s3_config_load()`:

| Key | Effect |
|---|---|
| `endpoint`, `region`, `bucket`, `access_key`, `secret_key` | All of endpoint/bucket/access_key/secret_key must be non-empty to enable S3 |
| `prefix` | Key prefix inside the bucket |
| `use_path_style` | `true`/`1` for path-style URLs (MinIO, some S3 clones) |
| `mode` | `mirror` (default: local copy kept, also stored in S3) or `offload` (moved to S3, downloads served via presigned redirects) |

Full reference: [S3.md](../S3.md). This file is a **secret** (credentials),
backup-only with `--with-secrets`.

## robots.settings (optional)

Crawler policy for `robots.txt` and `/llms.txt` (`robots_config_load()`):

| Key | Values | Default |
|---|---|---|
| `robots.level` | `allow` (everything), `restrict` (all except admin/private paths), `block` (Disallow: /) | `allow` |
| `llms.level` | `allow` (serve /llms.txt), `restrict` (serve it but disallow known AI crawlers), `block` (404 + disallow) | `allow` |

## upload.settings (optional)

MIME allow/deny policy for uploads (`upload_policy_load()`), detected by
libmagic content sniffing, not extension:

| Key | Default | Effect |
|---|---|---|
| `mode` | `denylist` | `denylist`: everything allowed except the list; `allowlist`: only the list is accepted |
| `denylist` | executables/script interpreters + `message/news` | Comma-separated MIME types; `image/` (trailing slash or `/*`) matches a subtree, otherwise exact case-insensitive match |
| `allowlist` | *(empty)* | Used when `mode=allowlist` |

## flywire.settings (optional)

FlyWire primary/replica sync — full documentation in [flywire.md](flywire.md):

| Key | Default | Effect |
|---|---|---|
| `mode` | *(empty = off)* | `primary` or `replica`; unknown values disable FlyWire |
| `primary_url` | *(empty)* | Where a replica polls, e.g. `https://example.com` |
| `token` | *(empty)* | Shared secret; replicas send it as `X-FlyWire-Token`. Primary requires it to serve the feed |
| `poll_seconds` | `2` | Replica poll interval, clamped 1–60 |
| `auto_upgrade` | *(off)* | `1` lets a replica run `./flywire-upgrade.sh` (git fetch/reset + build + service restart) when the primary advertises a different version |

## backup.settings (written by the admin dashboard)

Scheduled backup target — full documentation in [backup.md](backup.md):
`target` (`s3` or `dir`), `enabled`, `endpoint`, `region`, `bucket`,
`access_key`, `secret_key`, `prefix`, `use_path_style`, `path` (absolute
directory for `dir`), `keep` (default 14 archives), `passphrase`. File mode
0600, treated as a **secret**. Nothing runs until a target is registered and
`backup_settings_ready()` passes (`s3`: endpoint+bucket+keys; `dir`: absolute
path).

## Search (FTS5 + MeCab)

Post search is backed by a SQLite FTS5 index (`posts_fts`) replacing the old
hand-rolled trigram table. Two tokenizers are supported:

- **mecab** (default when available): requires `libmecab-dev` at build time
  (linked via pkg-config, `-lmecab` fallback) and the `mecab-ko-dic`
  dictionary at runtime. Korean text is indexed by morpheme, and compound
  queries are branched — e.g. `개발일지` becomes
  `("개발일지" OR (개발 AND 일지))` — so it matches both the exact surface and
  text written with different eojeol spacing (`개발 일지`).
- **trigram**: built into SQLite, used when MeCab is unavailable. Substring
  matching; terms shorter than 3 characters fall back to pure LIKE filtering.

The choice is made once at startup migration and stored in the
`search_tokenizer` site setting; deleting that row (or bumping the index
version in `src/db/search.c`) forces a rebuild on the next start.

| Variable | Default | Effect |
|---|---|---|
| `MECAB_DIC_DIR` | auto-detected (`/usr/lib/x86_64-linux-gnu/mecab/dic/mecab-ko-dic`, `/usr/local/lib/mecab/dic/mecab-ko-dic`, then MeCab default) | Directory of the `mecab-ko-dic` dictionary passed to `mecab_new2(-d …)`. Point it at a custom/user dictionary, or at a nonexistent path to force the trigram fallback |

## Environment variables

Enumerated from `getenv()` calls across `src/`. "—" means no default /
unset.

### Core

| Variable | Default | Effect |
|---|---|---|
| `BLOG_ROOT` | — | Site root override when `public/` is not in the current directory |
| `DEBUG` | — | Any value enables verbose CWIST/FLY logging (src/core/log.c) |
| `MV_DEBUG` | — | Debug flag in the media preview path |
| `CWIST_C1M_MODE` | `1` (set by the app itself) | Event-driven C1M reactor; set `0` to force the legacy thread-pool path |
| `NATS_URL` | — | e.g. `nats://localhost:4222`; enables the NATS messaging gateway |
| `BLOG_ECH_KEY` / `BLOG_ECH_DIR` | — | ECH (Encrypted Client Hello) key file / directory |

### Threading / workers

| Variable | Default | Effect |
|---|---|---|
| `FLY_REQUEST_WORKERS` | `16` | Async route worker count, must be 1–256 (`src/engine/async_route.c`) |
| `CWIST_WORKER_THREADS` | `cores*4`, clamped 16–128 | HTTP worker threads spawned by the CWIST framework (see TUNABLES.md) |

### Caching / inlining / media

| Variable | Default | Effect |
|---|---|---|
| `FLYBOARD_CACHE_MAX_MB` | unlimited | Soft cap on the in-memory page cache, 1–1024 MiB |
| `FLYBOARD_INLINE_IMAGES` | off | Inline images as base64 data URIs |
| `FLYBOARD_INLINE_ALL_ASSETS` | off | Also inline scripts/styles |
